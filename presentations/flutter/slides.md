# Por que o Flutter utiliza Dart?

<v-clicks>

- Linguagem fortemente tipada (mas nem tanto; pode ser configurada)
- Compilação Ahead of Time (para produção)
- Compilação Just in Time (para desenvolvimento)
- Orientada a objetos, porém com funções assíncronas
- Também possui um pacote RX para deixá-lo fortemente funcional
- Dart também produz código JavaScript para aplicações web

</v-clicks>
